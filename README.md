# sysinfo — сводка о системе для Linux / Raspberry Pi

[![build](https://github.com/paolosezart/sysinfo/actions/workflows/build.yml/badge.svg)](https://github.com/paolosezart/sysinfo/actions/workflows/build.yml)
![platform](https://img.shields.io/badge/platform-linux%20%7C%20arm64%20%7C%20armv7%20%7C%20amd64-blue)
![go](https://img.shields.io/badge/go-1.23%2B-00ADD8)
![license](https://img.shields.io/badge/license-MIT-green)

Утилита в духе Windows `systeminfo`, но заточена под Linux и Raspberry Pi 4B
(arm64). Один статический бинарник на Go, без зависимостей — просто скопируй
на плату и запусти.

## Зачем

`df -h` печатает симлинки и bind-mount'ы, `vcgencmd` выдаёт битовую маску
троттлинга, а `iw` — коды каналов. Приходится каждый раз лезть в мануалы.
`sysinfo` собирает всё в одну человекочитаемую сводку: без шума и без кодов,
которые надо расшифровывать вручную.

## Установка

Скачай готовый бинарник со страницы [Releases](../../releases):

```sh
# Raspberry Pi 4B / 5 (arm64)
curl -LO https://github.com/paolosezart/sysinfo/releases/latest/download/sysinfo-linux-arm64
chmod +x sysinfo-linux-arm64
./sysinfo-linux-arm64
```

Или собери сам (нужен Go 1.21+):

```sh
make arm64     # -> dist/sysinfo-linux-arm64
make release   # все цели + SHA256SUMS
```

## Что показывает

- **Система** — имя узла, ОС, ядро, архитектура, модель платы (device-tree),
  производитель, ревизия, серийный номер, часовой пояс, время загрузки и работы.
- **Процессор** — модель, производитель, ядра/потоки, текущая частота, а также
  минимальная и максимальная частота и губернатор (`cpufreq`).
- **Память** — ОЗУ (всего/использовано/свободно/кэш), swap и **ZRAM**:
  алгоритм сжатия, коэффициент, процент занятого, объём в сжатом виде и
  реально занятая в ОЗУ память.
- **Накопители** — только реальные файловые системы (`/`, `/home`, `/boot`,
  `/boot/firmware`, `/media/...`), с прогресс-баром, моделью устройства и
  классом/режимом шины SD-карты (`SDR104`, `Class 10`).
- **Сеть** — интерфейсы, IPv4/IPv6, MAC, трафик RX/TX, DNS-серверы и домены
  поиска; шлюз с MAC и вендором; для LAN: скорость линка, дуплекс, наличие
  кабеля; для Wi-Fi: SSID и BSSID точки доступа, диапазон и канал, скорость
  линка, ширина полосы, шифрование, сигнал.
- **Датчики (Raspberry Pi)** — температура, напряжения и такты `vcgencmd`,
  декодированный `get_throttled` (просадки питания/троттлинг: «сейчас» и
  «было с загрузки»), тепловые зоны, вентиляторы.
- **Дисплей** — разъёмы DRM и мониторы, разобранные из EDID: производитель,
  модель, разрешение и частота обновления, размер, серийный номер, год.
- **USB** — устройства с классом и протоколом интерфейсов (клавиатура, мышь,
  накопитель, хаб, аудио, видео), драйвером, скоростью линка и серийником.
- **Пользователи** — активные сессии из `utmp`: имя, тип подключения
  (локальный терминал / SSH), адрес клиента с обратным DNS, время входа,
  клиент SSH (если доступен), номер сессии и PID.
- **Язык** — интерфейс на русском и английском, определяется по локали
  (`LANG`/`LC_ALL`), принудительно — флагами `--ru` / `--en`.
- **Базы вендоров** — имена производителей USB и MAC подтягиваются из `usb.ids`
  и IEEE OUI. Актуальные базы **вшиты в бинарник**, поэтому расшифровка
  работает сразу, без интернета и без кэша. Команды `--vendor` и `--oui`
  обновляют локальную копию, только если на сервере появилась новая версия
  (условный запрос `If-None-Match`/`If-Modified-Since`) — лишний трафик не
  тратится.

## Сборка

```sh
make arm64     # Raspberry Pi 4/5 и другие 64-битные ARM  -> dist/sysinfo-linux-arm64
make armhf     # старые 32-битные Raspberry Pi            -> dist/sysinfo-linux-armv7
make amd64     # обычный x86-64 Linux                     -> dist/sysinfo-linux-amd64
make test      # тесты
make release   # все цели + SHA256SUMS
```

Вручную, без make:

```sh
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -trimpath -ldflags "-s -w" -o sysinfo .
```

Бинарник статический, зависимостей нет — просто скопируйте его на Pi:

```sh
scp dist/sysinfo-linux-arm64 pi@raspberrypi:~/
ssh pi@raspberrypi 'chmod +x sysinfo-linux-arm64 && ./sysinfo-linux-arm64'
```

## Использование

```
sysinfo                     # полная сводка (цветной вывод)
sysinfo --no-color          # без цвета
sysinfo --json              # машиночитаемый JSON (для скриптов и мониторинга)
sysinfo --cpu --ram         # только выбранные секции
sysinfo -sys -c -r -s -n -d -u   # короткие псевдонимы секций
sysinfo --ru / --en         # принудительный язык
sysinfo --demo              # пример вывода для Raspberry Pi 4B без железа
sysinfo --vendor            # обновить базу USB-вендоров (usb.ids)
sysinfo --oui               # обновить базу MAC-вендоров (IEEE OUI)
sysinfo --version           # версия и сборка
sysinfo --install           # установить в /usr/local/bin/sysinfo (повысит права через sudo)
```

Секции: `--system`/`-sys`, `--cpu`/`-c`, `--ram`/`-r`, `--storage`/`-s`,
`--network`/`-n`, `--sensors`, `--display`/`-d`, `--usb`/`-u`, `--users`.

Пример блока пользователей (`sysinfo --users`):

```
ПОЛЬЗОВАТЕЛИ
  raspi  [локальный терминал]
    Время входа: 11.11.2026 08:07:40
    Терминал: tty1
    Сессия: 1, PID 812

  raspi  [SSH]  192.168.100.42 (desktop.lan)
    Время входа: 11.11.2026 17:07:40
    Клиент: OpenSSH_9.6p1 Ubuntu-3ubuntu13
    Терминал: pts/0
    Сессия: 3, PID 1842
```

Клиент SSH показывается, только если утилита может прочитать окружение сессии
(запуск от root или от того же пользователя); в остальных случаях строка
«Клиент» просто отсутствует.

`sftp` и `scp` в списке не появятся: это подсистемы SSH, они работают без
псевдотерминала, и `sshd` не заводит для них запись в `utmp`. В списке виден
только интерактивный вход по SSH (у него есть свой pts). Отличить обычный SSH
от sftp/scp по этим данным нельзя — и утилита не выдумывает то, чего в данных
нет.

Переменная окружения `NO_COLOR` также отключает цвет.

## Зависимости во время работы

Ядро информации берётся напрямую из `/proc` и `/sys`, поэтому работает везде.
Дополнительные детали подтягиваются, если установлены соответствующие утилиты:

| Утилита   | Что добавляет                                   |
|-----------|-------------------------------------------------|
| `vcgencmd`| температура, напряжения, такты, `get_throttled` |
| `iw`      | SSID, канал, ширина полосы, шифрование Wi-Fi    |
| `ethtool` | скорость и дуплекс, если нет в `/sys`           |
| `resolvectl` | актуальные DNS-серверы systemd-resolved     |
| `loginctl` | список сессий на Debian 13 / systemd 257, где нет `/run/utmp` |

Если чего-то нет — секция просто деградирует, утилита не падает.

## Разработка

```sh
go vet ./...
go test ./...
```

Парсеры `/proc` и `/sys` вынесены в отдельные функции, поэтому их можно
проверять на фикстурах без реального железа — см. `sysinfo_test.go`
и `extra_test.go`.

Версия встраивается при сборке:

```sh
go build -ldflags "-X main.version=$(git describe --tags --always)"
```

`make` и CI подставляют её автоматически; без `-ldflags` значение равно `dev`.

## Кэш и базы вендоров

Локальные копии баз лежат в `$XDG_CACHE_HOME/sysinfo` (по умолчанию
`~/.cache/sysinfo`). Порядок поиска при расшифровке вендоров:

1. кэш пользователя (`~/.cache/sysinfo`);
2. системные копии дистрибутива (`/usr/share/ieee-data/oui.txt`,
   `/usr/share/misc/usb.ids` и т.п.);
3. база, вшитая в бинарник.

Последний пункт означает, что утилита показывает имена производителей
даже на машине без интернета и с пустым кэшем. Файлы обновляются командой
`sysinfo --vendor` / `sysinfo --oui`; если на сервере версия та же, загрузка
пропускается.
